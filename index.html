2. CKA Curriculum & Cheat Sheet

Cluster Architecture, Installation & Configuration

  • RBAC: Understand Roles, RoleBindings, ClusterRoles, and ClusterRoleBindings. Commands: kubectl create role, kubectl auth can-i
  • Kubeadm: Know how to bootstrap a cluster. Use kubeadm init and kubeadm join. Know how to upgrade the cluster (drain node, kubeadm upgrade, uncordon).
  • ETCD Backup & Restore: Critical exam topic. Use ETCDCTL_API=3 etcdctl snapshot save and snapshot restore. Must pass correct certs/keys.

Workloads & Scheduling

  • Deployments & Rollbacks: Know kubectl create deploy, kubectl rollout status, kubectl rollout undo.
  • Scheduling: NodeSelectors, NodeAffinity, PodAffinity/AntiAffinity, Taints and Tolerations.
  • ConfigMaps & Secrets: Create from literals/files. Mount them as environment variables or Volumes inside Pods.

Services & Networking

  • Services: ClusterIP (default), NodePort, LoadBalancer. Connect Pods via selectors.
  • Network Policies: Act as firewalls for Pods. Default deny-all vs specific allow rules (Ingress/Egress).
  • Ingress: Expose HTTP/HTTPS routes from outside the cluster to services. Requires an Ingress Controller (e.g., NGINX).
  • DNS: Understand CoreDNS. Pod DNS resolution: service.namespace.svc.cluster.local

Storage

  • Volumes: emptyDir (ephemeral), hostPath (node specific).
  • PersistentVolumes (PV): Cluster-wide storage resource. Know AccessModes (ReadWriteOnce, ReadOnlyMany, ReadWriteMany).
  • PersistentVolumeClaims (PVC): Namespace-bound request for storage. Pods mount the PVC, not the PV directly.
  • StorageClasses: Enables dynamic provisioning of PVs.

Troubleshooting

  • Node Failure: Check kubectl describe node. SSH into node, check systemctl status kubelet, check journalctl -u kubelet.
  • Pod Failure: kubectl describe pod (look at events at the bottom), kubectl logs <pod-name>. CrashLoopBackOff usually means application error.
  • Network Failure: Are endpoints created? kubectl get endpoints. Check CoreDNS pods. Check CNI (kube-flannel, calico) logs.
  • Evaluation: Always use --dry-run=client -o yaml to generate manifests quickly rather than writing from scratch.
